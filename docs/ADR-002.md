# ADR-002: Dependencies through FetchContent from git, pinned
- Context: GoogleTest, Google Benchmark, a property-testing library and HdrHistogram are needed; no system packages may be assumed.
- Decision: FetchContent with GIT_REPOSITORY and a pinned tag (commit for RapidCheck, which publishes no tags); versions listed in docs/VERSIONS.md.
- Alternative rejected: URL tarballs (blocked by this session's proxy) and vcpkg/Conan (extra toolchain for four libraries).
- Why: git fetch works everywhere this project builds, and a pin makes every build use identical third-party code.
- Consequence: first configure needs network; RapidCheck upgrades are by commit hash and must be bumped deliberately.
