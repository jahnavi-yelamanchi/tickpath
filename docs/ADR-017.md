# ADR-017: Differential checks: touched state every message, full state periodically
- Context: comparing every symbol's full book after every message is quadratic; a 20k-message deep-book run took 76 s against the oracle.
- Decision: after every message compare the status, every level the message touched (FIFO queue and aggregate), BBO of touched symbols, touched orders and order count; full snapshot of touched symbols every 64 messages; full-market hash at the end.
- Alternative rejected: full snapshot after every message, or final hash only.
- Why: a message can only change the levels and orders it names, so per-message checks still localise the first divergence to one message; periodic and final full checks catch corruption of untouched state.
- Consequence: debug-build infra suite runs in about 5 s; a bug that corrupts an untouched level is reported up to 64 messages late, with the final hash as backstop.
