# ADR-003: Warnings per target, sanitizers global
- Context: -Werror and clang-tidy must apply to project code but not to third-party code; sanitizer runtimes must instrument everything that runs.
- Decision: warnings and clang-tidy attach to project targets through `tickpath_target_defaults()`; sanitizer flags go through `add_compile_options` so dependencies are instrumented too.
- Alternative rejected: global CMAKE_CXX_FLAGS with -Werror.
- Why: a new compiler warning inside GoogleTest must not break the build, while TSan reports false positives if any linked code is uninstrumented.
- Consequence: every new project target must call `tickpath_target_defaults()`; clang-tidy runs in the debug preset only, to keep other builds fast.
