# ADR-007: Own RNG for generated feeds
- Context: generated feeds feed golden hashes and the replay check, so they must be byte-identical on every compiler and standard library.
- Decision: xoshiro256** seeded by splitmix64, bounded draws by rejection sampling, all in `sim/rng.hpp`.
- Alternative rejected: std::mt19937_64 with std::uniform_int_distribution.
- Why: the engine is portable but the distributions are not specified bit-for-bit, so libstdc++ and libc++ produce different feeds from the same seed.
- Consequence: golden values in tests hold across clang and GCC; any change to the generator's draw order changes them and must be deliberate.
