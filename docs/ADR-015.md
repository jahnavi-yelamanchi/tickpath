# ADR-015: Risk check semantics: far-side collar in basis points, fills-only position
- Context: the risk check needs a precise, integer-only definition before it is written, so tests can be written first.
- Decision: fixed check order (kill switch, zero qty, max size, reference present, collar, position); collar in basis points against the far side of the BBO; position from fills only, assuming the order fills completely (docs/RISK_CONTRACT.md).
- Alternative rejected: a collar in absolute price units, or a reference from the near side or midpoint.
- Why: basis points scale across a $1 and a $1,000 stock; the far side bounds how far an order can cross the market, which is the error a collar exists to catch.
- Consequence: `collar_bps` is capped at 1,000,000 so the products fit in 64 bits; open-order exposure is out of scope and noted as a limitation.
